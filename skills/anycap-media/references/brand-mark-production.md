# Brand mark production

Use this path for an explicit AnyCap logo, avatar, app icon, profile mark, or
other brand-adjacent symbol. It produces a reviewable candidate set; applying the
mark to a live account, repository, website, or product remains a separately
authorized publication change.

## Freeze the brief

Record the concept in one sentence, intended surfaces and real display sizes,
required and forbidden elements, background/alpha requirement, aspect ratio,
and exact palette values when color is constrained. Treat exact wordmarks and
letterforms as deterministic design assets, not generated pixels.

## Candidate gate

1. Generate four to six compositionally distinct concepts. Seed changes around
   one composition do not count as distinct concepts.
2. If the whole round is rejected, move to a disjoint concept space instead of
   refining rejected motifs.
3. Inspect every candidate with `image-read` for letters, numbers, pseudo-text,
   watermarks, borders, template traces, and forbidden elements. A new edit
   requires a new gate result.
4. After one composition wins, use image-to-image for colorways and change one
   variable at a time. Do not re-roll the composition from text merely to change
   hue.

## Decide at the consumer size

Build a deterministic comparison board that shows each candidate at the real
surfaces, normally including 64 px, 44 px, and 32 px. Review silhouette,
contrast, fused details, square-frame use, distinctiveness, transparent corners,
and light/dark backgrounds. The full-resolution image is not acceptance proof
for a thumbnail mark.

## Delivery record

Save the approved source asset, exported sizes, candidate board, prompt sidecar,
gate results, chosen colorway, and decision rationale together. Verify alpha and
actual dimensions after export. Stop at local delivery unless the current user
also authorized the exact remote placement.
