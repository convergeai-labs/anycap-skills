# AnyCap Promotional Video Style Reference

## What To Learn From References

A strong reference commits to one physical metaphor: e.g. a retro broadcast desk for a software-usage product. The composition is symmetrical, the product name is integrated into the set, and the operators make modern software feel tangible.

Codex official material keeps the message simple: one person or one product surface, one large headline, and enough real-world context to feel credible.

Claude Code positions itself as agentic work, not autocomplete. Its strongest message is whole-project execution: read the codebase, edit files, run tests, and deliver finished work.

Cursor presents the agent inside a polished IDE world. The lesson is not to over-explain. Show a tasteful product environment, then make the action feel obvious.

## AnyCap Translation

AnyCap should not look like another coding agent. It should look like the capability layer around coding agents.

Use this mental model:

- Codex, Claude Code, Cursor: operators or workstations.
- Human: gives intent and checks the result.
- Robot/agent: the autonomous worker.
- AnyCap: the switchboard/runtime that connects the agent to media, vision, web, uploads, and delivery.
- Output: finished artifacts, not chat text.

## Visual Direction

- Primary setting: agent operations room, capability desk, or compact broadcast control room.
- Composition: centered hero desk, clear subject hierarchy, 16:9 cinematic frame.
- Palette: warm studio neutrals, walnut/charcoal surfaces, AnyCap olive and pale green accents, restrained blue monitor glow.
- Lighting: soft key light, practical monitor light, small indicator lights.
- Motion: slow dolly, switches lighting up, monitors changing, robot head movement, operator hand gesture.
- Branding: exact AnyCap mark and wordmark added locally. AI-generated signage should be blank.

## Copy Rules

- Use large, short claims:
  - "Keep your agent. Add capabilities."
  - "AnyCap gives agents tools for the outside world."
  - "Create. Inspect. Retrieve. Deliver."
- Use one support line per scene at most.
- Never use small terminal text as the main narrative.
- Never put copy over busy detail without a darkened text-safe region.

## Anti-Patterns

- Dark grid with random diagonal lines.
- Floating UI cards competing for attention.
- Three-column explainer cards inside the hero.
- Tiny CLI or terminal lines that nobody can read.
- AI-generated product labels or logos.
- Overloaded first frame.
- A video that only says "CLI" instead of showing capability outcomes.
